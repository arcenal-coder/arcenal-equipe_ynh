Connecter Élise à Hermes · MCP

  1. Dans Hermes, ajouter un serveur MCP HTTP nommé arcenal-elise, dans le profil elise.
  2. Renseigner l’adresse ci-dessous.
  3. Créer un jeton ici et le coller dans le champ « Bearer token » de Hermes, puis enregistrer et tester le serveur.

Hermes gère ensuite les appels aux outils. Aucun programme local ni configuration spéciale des arguments n’est nécessaire.

Jeton à copier dans Hermes

Ce jeton ne sera affiché qu’à sa création. Il donne accès aux outils d’Élise avec vos droits LDAP ; les actions sont attribuées à votre utilisateur. Validité : 90 jours, révocable ci-dessous.
